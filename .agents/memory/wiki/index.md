# Project wiki

**Purpose**: a web app where one person with a Google account builds a single mind map of ideas (titled nodes): create, edit, delete, collapse and navigate by focus. Later: nodes of other kinds (Drive document, spreadsheet, event, task, repo).

**Status**: the first slice has the backend and the SPA. Slice 2 is pending (drag and reorder with `sort_key`, Drive).

**Components**
- `api` (implemented): FastAPI (Python 3.12) in `api/app/` with the modules `auth`, `nodes`, `settings`, `node_types` and `integrations` (empty). SQLAlchemy 2 + Alembic. Routes under `/api`: `auth` (login, callback, logout), `me`, `me/settings`, `nodes/{id}/view`, `nodes/{id}/children`, `nodes/{id}` (`PATCH`; `DELETE` with `?children=cascade|reparent`, default `cascade`; `reparent` moves the direct children up to the parent in one transaction).
- `db` (implemented): PostgreSQL 16 with the `db-data` volume. Tables `users`, `sessions`, `maps`, `nodes` (`kind` + `props`).
- `web` (implemented): React + TypeScript SPA with Vite in `web/src/`. React Router for `/` and `/n/:nodeId`; React Flow with a horizontal tree layout computed on the client (`map/layout.ts`); API client in `web/src/api/client.ts`, which sends `X-CSRF: 1` on mutations. Double-click focuses; Tab/Enter/F2/Space/Delete/arrows edit and navigate. The "+" button on each node (`IdeaNode`, `nodeActions.createChild` → `useMapView.startCreateChild`) creates a child in edit mode, same as Tab; on edge nodes it first moves the focus one level toward the node, and on collapsed nodes it expands them first. The "?" button in the header (`components/ShortcutsHelp.tsx`) opens the shortcuts panel. The hint "Tap + or Tab to add an idea" shows when the focus is on the real root with no children (`MapPage.tsx`). The 🗑 button on each non-root node (`IdeaNode`, `nodeActions.remove` → `useMapView.remove`): a leaf is deleted without asking; a node with children opens `components/DeleteDialog.tsx` (its own dialog, initial focus on "Cancel", Escape cancels) with "Delete everything from here" (cascade), "Delete only this one and move its children up" (reparent; the window is then requested again) and "Cancel". The Delete key does the same. After an edit, focus returns to the map container. API types are in `web/src/api/schema.ts`, regenerated with `pnpm --dir web gen:api`.
- Login: the backend runs the Google OAuth flow and the browser receives an `HttpOnly` cookie. Scopes `openid email profile`. Mutations require the `X-CSRF: 1` header. The SPA shows the login screen on a `401`.

**How to run**: copy `.env.example` to `.env` (`POSTGRES_PASSWORD`, `DATABASE_URL`, `SESSION_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`) and run `docker compose up --build`. The step-by-step guide to creating the Google OAuth credentials is in the Installation section of `README.md`. The SPA is at `http://localhost:5173` (proxies `/api` to `api:8000`) and the API at `http://127.0.0.1:8000` (docs at `/docs`). Outside Docker: `pnpm --dir web dev`. Tests: `uv run --directory api pytest -q --cov=app --cov-fail-under=80` and `pnpm --dir web exec vitest run --coverage`. The backend tests need a PostgreSQL: `TEST_DATABASE_URL`, testcontainers (Docker running) or the embedded `pgserver`. They never use the development database.

Backend in `api/` (package `api/app/`, tests in `api/tests/`, environment managed with `uv`).
